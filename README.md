# Ćwiczenia 1 – Git i GitHub (APBD)

Niewielka aplikacja konsolowa w C# (.NET), rozwijana w kolejnych commitach w ramach ćwiczeń z Gita:
fast-forward, three-way merge bez konfliktu oraz merge z konfliktem i jego ręcznym rozwiązaniem.

## Opis programu

Program wyświetla powitanie oraz statystyki dla tablicy liczb całkowitych
(np. sumę elementów). Logika obliczeń znajduje się w klasie `StatisticsHelper`,
a treść powitania w klasie `Greeting`.

## Uruchomienie

Wymagany jest zainstalowany .NET SDK.

```bash
git clone https://github.com/TWOJ_LOGIN/apbd-cw1-git.git
cd apbd-cw1-git
dotnet build
dotnet run
```
